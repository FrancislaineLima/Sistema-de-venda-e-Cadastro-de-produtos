# 🌸 Sistema de Vendas
https://sistemadevendafsystem.streamlit.app/

Este é um projeto de um Sistema de Vendas construído com Python e Streamlit. O aplicativo permite o cadastro rápido de vendas diárias e gera um dashboard interativo e estilizado para análise de faturamento.

## 🎓 Sobre o Projeto

Este projeto foi desenvolvido com base nos conhecimentos adquiridos durante o **Imersivo em Python** da **Hashtag Programações**. A partir da base construída no evento, foram adicionadas personalizações visuais, como uma paleta de cores customizada em tons de rosa pastel para os gráficos, garantindo um design único e agradável.

## ✨ Funcionalidades

* **📝 Cadastro de Vendas:** Formulário intuitivo para registrar a data, vendedor, produto, quantidade e valor da venda.
* **📋 Tabela de Dados:** Visualização em tempo real das vendas cadastradas no sistema.
* **📊 Dashboard de Faturamento:** Gráficos interativos (Barras e Rosca/Donut) para analisar o desempenho por vendedor e a participação de cada produto no faturamento total.
* **🎨 Design Personalizado:** Gráficos estilizados com uma paleta de cores **Rosa Pastel** customizada de alto contraste, utilizando o Plotly.

## 🛠️ Tecnologias Utilizadas

* [Python]
* [Streamlit]
* [Pandas]
